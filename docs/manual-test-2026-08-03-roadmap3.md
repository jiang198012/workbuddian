# 手测详单：ROADMAP 3.0（R1-R6，2026-08-03）

> 被测构建：main `1578a82` 之后（含 R1-R6 全部 commit）。环境：Obsidian + demo-vault + WorkBuddy 已登录。
> 旧清单 `manual-test-2026-08-03-acp-v2.md` / `-step2.md` 不重复；本单只含 3.0 新功能。

## R3-1. inline edit 词级 diff（R1）
- 步骤：编辑器选中一段文字 → 命令「用 CodeBuddy 编辑选区」→ 输入「把语气改正式」→ diff 弹窗。
- 预期：变更行内只有**实际改动的词/字**有加深高亮（不是整行一色）；接受后选区被替换。
- PASS 判定：行内高亮精确 + 接受/拒绝正常。

## R3-2. 流式渲染节流（R2）
- 步骤：发「写一篇 800 字的文章介绍 ACP 协议」。
- 预期：长文流式滚动流畅、无卡顿；结束后正文完整无丢字；思考指示器在首个 chunk 到达时正常消失。
- PASS 判定：渲染节奏平滑 + 内容完整。

## R3-3. 自动会话标题（R3）
- 步骤 1：新建会话发「帮我梳理一下 RAG 的核心概念」→ 首轮回复完成后看标签页标题。
- 预期：标题从截断文本变为 AI 生成的概括标题（≤20 字）。
- 步骤 2：再建会话，发消息后**立即手动重命名** → 首轮结束后标题保持你改的名字（不被覆盖）。
- 步骤 3：设置页关掉「自动生成会话标题」→ 新会话保持截断标题。
- PASS 判定：自动生成 + 改名保护 + 开关生效。

## R3-4. @mention 四源聚合（R4）
- 前置：设置页配好至少一个子代理与一个 MCP 服务器（见 step2 清单 S2-2/S2-3）。
- 步骤：输入框敲 `@` → 下拉应同时出现 `@Agents/<名>`、`@mcp/<名>`、vault 文件三组候选；继续输入过滤。
- 选中行为：`@Agents/x` 与 `@mcp/x` 插入 `@x ` 文本；md 笔记插 `@[[名]]`；非 md 文件进附件 chips。
- PASS 判定：四源出现且各自选中行为正确。

## R3-5. MCP 管理 UI（R5）
- 步骤：设置页「MCP 服务器」区——① 点「添加服务器」填名称/命令（如 `node /tmp/fake-mcp-server.mjs`）保存 → 列表出现该行、JSON textarea 同步；② 行内开关停用 → JSON 里出现 `disabled:true`；③ 铅笔编辑改名 → 保存生效；④ 垃圾桶删除；⑤「从剪贴板导入」：复制 `{"mcpServers":{"fs":{"command":"npx","args":["-y","pkg"]}}}` 后点导入 → 列表新增 fs 行。
- 预期：所有操作写回 JSON 文本框；停用项不注入会话（可用「查看日志」或新会话调用验证：停用的服务器工具不再出现）。
- PASS 判定：增删改停用导入全通 + JSON 同步。
- 说明：传输形态锁 stdio（探针实测 ACP 对 http/sse 形态报 Invalid params）。

## R3-6. 子代理 tools/model 键（R6）
- 步骤：子代理 JSON 加 `tools`/`model` 键，如 `{"reviewer":{"description":"审查","prompt":"只回一行","tools":["Read"],"model":"auto"}}` → 会话里唤起 reviewer。
- 预期：Agent 工具正常调用（CLI 接受该 schema，探针已验证不炸不拒）。
- PASS 判定：唤起成功。
