## 1. R1：inline edit 真词级 diff

- 现状：`features/inline-edit/index.ts` 的 DiffModal 行级展示；`shared/wordDiff.ts` 已在聊天 diff 验收。
- 机制：读 DiffModal 当前渲染——若与聊天 diff 结构同构则复用 `renderDiffRows` 同款配对高亮（remove/add 成块按下标配对）；否则最小改造接入 `splitInlineDiff`。接受/拒绝逻辑不动。
- 验收：选区编辑 modal 中变更段行内高亮；`npm run build` 过；手测用例。

## 2. R2：流式渲染节流

- 现状：input.ts 每个 text chunk 都 `await renderMarkdownContent`（全量 markdown 重渲染）。
- 机制：sendText 内加渲染协调——text chunk 只更新 `textContent` 与 `manager.updateMessage(...,skipSave)`；DOM 渲染走调度器：`requestAnimationFrame` + 距上次渲染 ≥150ms 才执行，否则挂起最新快照；首个 chunk（移除思考指示器）与流末/catch/finally 强制 flush。参照 Claudian `StreamingRenderCoordinator` 语义但不引其代码。
- 验收：jest 全绿（时序相关用例如有受影响按新节奏校准）；手测长文流式无卡顿、无丢字。

## 3. R3：自动会话标题

- 机制：首条 user 消息的首轮**结束后**（done），若 `enableAutoTitle`（新设置项，默认开）且标题仍是截断 fallback → 一次性辅助会话：`api.sendMessage(api.generateId(), titlePrompt)` 收集 text chunk（≤20 字、无标点结尾、中英文跟随用户内容语言）→ `manager.renameConversation`（用户已手动改名则不覆盖：rename 前比对当前标题仍等于 fallback）。titlePrompt 模板进 i18n（中英）。
- 设置项：`autoTitle: boolean`（settings v11 沿用，本批未发布）；设置页「上下文注入」组加开关。
- 验收：types/api 层测试（fallback 比对逻辑抽到 `shared/` 纯函数 `shouldApplyAutoTitle(currentTitle, fallback)` 并测试）；手测新会话自动命名。

## 4. R4：@mention 四源聚合

- **前置探针**（先跑，决定形态）：① `session/new` 附带 `additionalDirectories`（及 `extraDirectories`/`addDirs` 候选键）是否被 CLI 接受并生效（让 CLI 读目录外文件不弹卡）——预期多数被拒/忽略，则外部目录维持"附件+批准卡"；② 无协议注入时，@ 外部文件 = 加入附件 chips。
- 机制（探针后定型，默认形态）：@ 下拉数据源扩为四组——vault 笔记（现有）/ vault 任意文件（非 md 选中→附件）/ `@Agents/`（读 `settings.customAgentsJson` 的键，选中注入 `@<agent名> ` 文本）/ `@mcp/`（读 `mcpServersJson` 的 name，选中注入 `@<name> ` 文本——依赖 R10 的激活机制，本期只注入文本不改注入集合）。现有 `@[[note]]` 行为不动。
- 验收：`atReferences` 解析层纯函数测试（新文本形态不破坏既有解析）；build；手测四组可选中。

## 5. R5：MCP 管理 UI

- **前置探针**：`session/new` 的 mcpServers 元素带 `{type:'sse', url}` / `{type:'http', url, headers}` 是否被接受（结果/报错）。被接受 → 表单开放三类型；只认 stdio → 表单锁 stdio。
- 机制：设置页「MCP 服务器（JSON）」textarea **上方**加列表 UI：现有 JSON 解析为列表（名称/类型/启停），增删改经 modal 表单（name/command/args/env 或 url/headers + enabled）；写回 JSON 文本（保持单一真相=JSON 字符串，不新增存储字段）。剪贴板导入按钮（识别 `mcpServers` 包装/单服务器两种形态）。**不做**连接测试 modal（需引 MCP client 依赖，YAGNI 本期）。
- 验收：build；手测增删改后新会话生效。
