### WB-QA-001：输入框高度设置

证据：本轮重读 `src/features/chat/input.ts:56`，自动高度仍固定调用 `clampTextareaHeight(scrollHeight, 30, 200)`；设置类型和设置页未发现对应上下限、自动高度字段。这是用户先前明确提出的需求缺口，不是本轮证实的“收缩回归”。手动拖动能力尚未验收。

- [x] 提供手动调整高度、自动调整开关、最低/最高阈值，并说明手动与自动模式的关系（已实现，待 GUI 验收）。
- [x] 上下限持久化；空值、非数字、负数及最低值大于最高值回落默认范围（已实现并有迁移测试）。
- [ ] 在 demo-vault 中输入长文本到最高阈值，再逐步删除：高度随内容减少，最终到最低阈值。
- [ ] 关闭自动模式、重新打开插件后，行为与保存设置一致；留下前后截图和实测高度。

实现记录：设置迁移版本升至 15；默认自动调整、30–200px；允许配置范围 20–600px；已通过定向测试、全量 Jest（61 suites / 728 tests）和生产构建。Force Reload 后 CUA 窗口未恢复，以上两项 GUI 验收待窗口恢复后补做。
