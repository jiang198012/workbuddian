## 测试用例(按序执行,每项记录 ✔/✗ + 现象)

### A. 基本聊天(核心体验)
1. 在输入框输入"你好,简单介绍下自己",按 Enter。
   - 预期:先出现"思考中…",随后**逐字流式**输出,结束后占位消失。
2. 让它"读一下 demo-vault 里 微调与对齐.md 讲了什么"。
   - 预期:出现工具调用块(读文件),完成后有内容。
3. 让它"输出一个 Markdown 表格 + 一段 python 代码"。
   - 预期:表格和代码块正确渲染。

### B. 会话管理(dual-pane 核心)
4. 点左侧栏"+"新建对话 → 发一条消息。
   - 预期:新会话出现在左侧列表,可切换。
5. 在左侧会话列表**右键**任意会话 → "置顶会话"。
   - 预期:该会话跳到最前 + 📌 标识;再右键可取消。
6. 在左侧栏搜索框输入关键词(如"学习")。
   - 预期:列表实时过滤,命中标题高亮,Esc 恢复。
7. 右键某会话 → "删除" → 观察确认弹窗。
   - 预期:弹"确认删除?"按钮,不点则 3 秒自动消失;点确认才删。
8. 输入 `/resume` 回车 → 弹会话选择器,搜索框过滤。
   - 预期:可选历史会话恢复。

### C. 权限与批准(需真实 CLI 登录)
9. 让它"在 demo-vault 里创建一个新文件 test.md,写入 Hello"。
   - 预期:弹批准卡(Write 路径+行数),批准后写入,完成态有 diff + 撤销按钮。
10. 点批准卡上的"撤销此修改"。
    - 预期:文件恢复原状,撤销有安全确认。
11. 切"完全访问"模式,再让它编辑文件。
    - 预期:不弹批准卡,直接执行。

### D. 新功能专项
12. 输入 `/translate`,回车。
    - 预期:输入框填入翻译模板("请把下面的内容翻译成中文…"),可编辑。
13. 输入 `@stats` + 问题。
    - 预期:AI 能看到 vault 统计(文件数/标签)。
14. 点模型按钮(显示中文名如"DeepSeek V4 Pro 深度求索")。
    - 预期:菜单列出国内模型中文名,选中生效。
15. 构造高用量会话(大量对话),观察输入框上方。
    - 预期:用量 ≥80% 时出现"上下文已用 NN%"预警条 + 压缩/新建按钮。
16. 侧栏打开聊天面板(窄面板)。
    - 预期:侧栏**没有** dual-pane 左侧栏,保持顶部标签(不挤占聊天区)。

### E. 鲁棒性(用户会遇到)
17. 发消息后,在"查看日志"或控制台确认 `[WB]` 日志正常,无红色 Error。
18. 快速连续:新建会话 → 发消息 → 切会话 → 再发,来回 5 次。
    - 预期:无崩溃,状态一致。
19. Cmd+R 重载 Obsidian。
    - 预期:会话历史恢复,可继续对话,无数据丢失。
20. 双面板:侧栏 + 主面板各开一个,分别发不同消息。
    - 预期:两面板互不干扰,各自显示自己的对话。
